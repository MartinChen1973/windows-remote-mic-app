# 指挥目标锁定（Command sink）

日期：2026-11-13（更新：OK 两步粘贴与延迟发送）

## 用途

在其他窗口浏览时，用微信（等）语音把文字写入剪贴板，再粘贴到已锁定的聊天输入框（例如 Cursor Agent），无需常开 Cursor 前台。

## 仅需映射一个动作

在 **指挥目标** 分组中只配置 **指挥目标锁定**（建议绑在空闲键，如主页或 YouTube）。  
**确定（OK）** 在已锁定时的行为由程序接管，不必再选「粘贴」或「发送」。

## 操作顺序（已锁定）

1. **语音键**：开始微信输入法说话。
2. **OK 第一次单击**：记录当前剪贴板基线（序列号与文本）。
3. **OK 第二次单击**：开始轮询剪贴板；微信写完新文字后 **自动 Ctrl+V 到锁定输入框**（最多等待约 120 秒）。
4. **OK 双击**：向锁定输入框发送回车（提交）。若在步骤 3 仍在等待微信，则 **提交会推迟到粘贴完成之后**。

未锁定时，OK 仍按你在按键映射里配置的动作执行（例如单击 Ctrl、双击 Enter）。

## 托盘与任务栏指示（接收服务已连接时）

- **绿点**：指挥目标已真正锁定，可以说话。
- **橙点**：未锁定，请勿对 Cursor 说话（含按下锁定键后尚未成功锁定、或已解锁时）。
- 通知区与设置窗口图标、任务栏按钮共用同一套角标（开发版标题 **1.0.107+**）。
