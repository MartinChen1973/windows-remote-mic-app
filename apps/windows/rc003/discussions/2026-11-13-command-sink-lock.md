# 指挥目标锁定（Command sink）

日期：2026-11-13（更新：OK 两步粘贴与延迟发送）

## 用途

在其他窗口浏览时，用微信（等）语音把文字写入剪贴板，再粘贴到已锁定的聊天输入框（例如 Cursor Agent），无需常开 Cursor 前台。

## 仅需映射一个动作

在 **指挥目标** 分组中只配置 **指挥目标锁定**（建议绑在空闲键，如主页或 YouTube）。  
**确定（OK）** 在已锁定时的行为由程序接管，不必再选「粘贴」或「发送」。

## 操作顺序（已锁定）

1. **OK 第一次单击**：发送你在「确定 · 单击」里配置的映射（例如左 Shift+Ctrl+Win 启动微信输入法），并记录剪贴板基线。
2. **OK 第二次单击**：**再次发送同一「确定 · 单击」映射**（结束微信输入法），然后开始轮询剪贴板；有新文字后 **自动 Ctrl+V 到锁定输入框**（最多等待约 120 秒）。
3. **OK 双击**：向锁定输入框发送回车（提交）。若在步骤 2 仍在等待剪贴板，则 **提交会推迟到粘贴完成之后**。

**绿点（已锁定）时**，只有上述 OK 流程会执行；「确定 · 双击」等其它手势在单击分支里不会单独注入（双击仍走提交）。  
**橙点（未锁定）时**，OK 完全按你在按键映射里配置的动作执行。

## 托盘与任务栏指示（接收服务已连接时）

- **橙点**：未锁定，可以正常连接，但请勿对 Cursor 说话。
- **绿点**：指挥目标已成功锁定，可以说话。
- **红点**：按了锁定键但当前焦点不是可编辑输入框，锁定失败；请聚焦聊天输入后再试。解锁或锁定成功后会离开红点。
- **Cursor / VS Code**：聊天输入在 Chromium 渲染控件（`Chrome_RenderWidgetHostHWND`）内，锁定时会用 UIA 辅助识别，不要求传统 Win32 `Edit` 类名。
- 通知区与设置窗口图标、任务栏按钮共用同一套角标（开发版标题 **1.0.107+**）。
