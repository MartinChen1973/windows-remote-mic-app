# 指挥目标锁定（Command sink）

日期：2026-11-13

## 用途

在其他窗口浏览或滚动时，将语音 IME 写入剪贴板的文字粘贴到已锁定的聊天输入框（例如 Cursor Agent），并在需要时向同一输入框发送回车。

## 操作约定

1. 在目标聊天输入框聚焦时，按遥控器上绑定了 **指挥目标锁定** 的键：再次按下可解锁。
2. 托盘图标：绿点表示已锁定、可说话；双竖线（暂停样式）表示未锁定。
3. **指挥目标粘贴**：将当前剪贴板内容粘贴到已锁定输入框（须先锁定，否则失败且剪贴板不变）。
4. **指挥目标发送**：向已锁定输入框发送回车（提交）。
5. 目标失效时自动解锁，托盘约 8 秒内显示一次说明气泡（可配置为 5–10 秒量级）。

## 按键配置

在设置 → 按键映射 的 **指挥目标** 分组中选择上述三项并绑定到遥控器按键（例如锁定、粘贴、发送）。

## 实现说明

- 状态文件：`%LOCALAPPDATA%\RemoteMic\RC003\command_sink_state.json`
- 粘贴/发送时会短暂激活目标窗口后恢复先前的活动窗口。
